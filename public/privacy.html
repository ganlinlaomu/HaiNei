English

1. About this policy

HaiNei is a Nostr-based social and private messaging application operated by Hainei. This policy explains how HaiNei handles service data and how it accesses, uses, stores, and shares Google user data.

2. Google user data

When a user selects “Continue with Google,” HaiNei uses Google OAuth with openid and https://www.googleapis.com/auth/drive.appdata.

HaiNei uses Google data only to identify the Google Account selected for recovery and to create, read, and manage HaiNei encrypted backup files in Google Drive appDataFolder.

HaiNei does not access regular Google Drive files, Google Photos, Gmail, Google Contacts, Google Calendar, or unrelated Google content.

3. Purpose and storage

Google user data is used only to provide account recovery: identify the recovery account, find encrypted backups, create encrypted backups, restore a Nostr account on another device, and manage the user’s own recovery data.

The Nostr private key is encrypted locally before backup. HaiNei does not upload the recovery PIN or an unencrypted Nostr private key to Google Drive. Backup filenames do not contain the user’s Nostr public key.

4. Google OAuth access tokens

Google OAuth access tokens are used only for required API requests during the current authorization session. HaiNei does not persist these tokens in browser Local Storage, Session Storage, or IndexedDB.

5. Sharing and Limited Use

HaiNei does not sell Google user data. Data obtained through Google APIs is not shared with third parties except when necessary to provide a feature expressly requested by the user, with explicit user consent, or where required by law.

HaiNei uses Google user data only to provide or improve user-facing HaiNei functionality and intends to comply with the Google API Services User Data Policy, including applicable Limited Use requirements. Google user data is not used for advertising, sale of data, user profiling for advertising, or training general-purpose AI models.

6. Nostr and local data

Nostr is decentralized. Public posts, profile information, and other Nostr events may be transmitted to Nostr Relays and retained by third-party Relays or clients. HaiNei cannot guarantee deletion of already-published information from every participant in the Nostr network.

HaiNei may store account information, friends, messages, read state, application settings, encrypted media cache, and encrypted key material locally on the user’s device.

7. User controls and deletion

Users may stop using Google recovery, revoke HaiNei OAuth access from their Google Account, clear local HaiNei data, or stop using the service. Revoking OAuth access does not necessarily delete an existing backup already stored in Google Drive appDataFolder.

For questions or requests concerning recovery data or deletion, contact kudos-zap-citrus@duck.com.

8. Security and changes

HaiNei uses reasonable safeguards including HTTPS, local encryption, encrypted Nostr protocols, minimal Google OAuth scopes, session-only Google access tokens, and encryption before Google Drive upload. No networked system can guarantee absolute security.

Material changes to data handling or Google API use will be reflected in this policy.

繁體中文

隱私權政策摘要

HaiNei 由 Hainei 營運。使用「使用 Google 繼續」時，HaiNei 僅使用 openid 與 drive.appdata，用途是識別恢復帳號以及在 Google Drive appDataFolder 中建立、讀取及管理 HaiNei 的加密備份。

HaiNei 不會存取一般 Google Drive 文件、Google Photos、Gmail、聯絡人或 Google Calendar。Nostr 私鑰會先在裝置上加密；恢復 PIN 與未加密私鑰不會上傳。Google access token 不會永久儲存在 Local Storage、Session Storage 或 IndexedDB。

HaiNei 不出售 Google 使用者資料，不將其用於廣告、廣告側寫、資料販售或通用 AI 模型訓練。除提供使用者明確要求的功能、使用者明確同意或法律要求外，不向第三方分享透過 Google API 取得的資料。

Nostr 為分散式協議，已公開到 Relay 的內容可能被第三方保存。使用者可撤銷 Google OAuth、清除本機資料或停止使用服務。資料相關問題請聯絡 kudos-zap-citrus@duck.com。

プライバシーポリシー概要

HaiNei は Hainei が運営しています。「Google で続ける」を利用する場合、HaiNei は openid と drive.appdata のみを使用し、復元用アカウントの識別、および Google Drive appDataFolder にある HaiNei の暗号化バックアップの作成・取得・管理に利用します。

Google ユーザーデータを販売せず、広告、広告目的のプロファイリング、データ販売、汎用 AI モデルの学習には使用しません。必要なユーザー機能、明示的な同意、または法令上の義務がある場合を除き、第三者に共有しません。
